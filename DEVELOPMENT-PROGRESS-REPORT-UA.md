# Звіт про прогрес розробки — 2026-04-04

## Загальний підсумок

Цей звіт оцінює поточний стан розробки **Порталу де-ідентифікації клінічних даних** (Команда Orange) станом на 4 квітня 2026 року у порівнянні з повною референсною реалізацією. Проєкт є завданням стажування, де дві команди (Orange, Green) змагаються у побудові однакової платформи анонімізації медичних даних.

**Загальний прогрес: ~16% (Бекенд ~17%, Фронтенд ~15%)**

Проєкт перебуває на стадії **первинного скаффолдингу / ранньої розробки**. Інфраструктура здебільшого готова (Docker, NestJS bootstrap, скелет React + Vite, MUI тема, i18n). Лендінг-сторінка — єдина повноцінно реалізована функція. **Жоден із 5 основних бекенд-модулів** (Auth, Users, De-Identification, Jobs, Synthetic Data, Dashboard) не розпочато. **Немає Redux стейт-менеджменту, немає API-сервісів, немає компонентів бізнес-логіки та немає тестів.**

## 4. Оцінка процесу розробки

### Позитивні аспекти

- **Ініціативність Ігната** — побудував референсний проєкт до старту спринту; взяв на себе інфраструктурні завдання; створив повний пайплайн транскрипції аудіо для документування всіх мітингів
- **Чисті архітектурні патерни** — винесення хуків (useSidebar, useHeader, useMainLayout), коректний TypeScript усюди
- **Якість лендінг-сторінки** — добре зроблена з адаптивним дизайном, MUI-темою, коректним i18n
- **Підготовка i18n** — ключі перекладу створені заздалегідь для ще не побудованих функцій
- **Робота з темою** — детальніша за специфікацію з кастомними розширеннями палітри

### Ризики та проблеми

| Проблема | Серйозність | Деталі |
|----------|-------------|--------|
| **Основна функція не розпочата** | Критична | Інтеграція Presidio (ціннісна пропозиція продукту) має нуль коду після 2 тижнів |
| **Немає автентифікації** | Критична | ProtectedRoute є прохідним — будь-хто може отримати доступ до /app/* маршрутів |
| **Немає стейт-менеджменту** | Висока | Redux store порожній — немає slices, thunks, потоку даних |
| **Немає тестів** | Висока | Жодного тест-файлу, фреймворк тестування навіть не у devDependencies фронтенду |
| **Дисфункція команди** | Висока | Бекенд-волонтер зник, PR не рев'юються 2+ дні, бекло не існував перший тиждень |
| **Немає Definition of Done** | Середня | Відсутні критерії прийняття для будь-якої функції |
| **Немає API-контракту** | Середня | Swagger/OpenAPI специфікація не створена до початку розробки |
| **Баги конфігурації** | Середня | Рядки-заглушки в конфігурації бекенду спричинять NaN помилки |
| **Небезпечний CORS** | Середня | `origin: "*"` у бекенді — має бути конфігурованим |
| **Вузьке місце дизайнера** | Середня | Дизайни змінювалися посеред спринту, спричиняючи переробки |
| **Відсутня міграція Jobs** | Низька | `1710000000001-CreateJobsTable.ts` відсутня |

### Прогалини у процесі

1. **Бекло не існував** до 27 березня (8 днів після старту проєкту)
2. **PR-дисципліна** неодноразово порушувалась — кілька комітів на PR, нерев'ювані PR блокують прогрес
3. **Знання жили у мітингах**, а не в документації — що спонукало Ігната побудувати пайплайн транскрипції
4. **Інфраструктурні проблеми** (видалений Docker-конфіг, неконсистентні локальні БД) тривали протягом спринту
5. **Дошка спринту була порожньою** щодо нових задач до 3 квітня

## 6. Рекомендації (за пріоритетом)

1. **Негайно реалізувати Auth модуль** — Без автентифікації нічого не працюватиме end-to-end. Бекенд: AuthService + JwtStrategy + Guards. Фронтенд: authSlice + authService + сторінка Auth + ProtectedRoute.

2. **Побудувати pipeline де-ідентифікації** — Це ядро продукту. Бекенд: PresidioService + DeIdentificationService. Саме це відрізняє проєкт від звичайного CRUD-додатку.

3. **Підключити Redux store** — Створити як мінімум authSlice та jobsSlice. Без стейт-менеджменту сторінки не можуть функціонувати.

4. **Додати API-сервіси** — З'єднати фронтенд із бекендом через типізовані сервісні модулі.

5. **Виправити конфігурацію бекенду** — Замінити рядки-заглушки помилок на розумні значення за замовчуванням. Додати відсутні env-змінні (JWT_SECRET, PRESIDIO_*, ENCRYPTION_KEY).

6. **Виправити ProtectedRoute** — Зараз будь-хто може отримати доступ до захищених маршрутів. Необхідна перевірка наявності JWT та редірект.

7. **Додати інфраструктуру тестування** — Як мінімум додати Vitest + testing-library до devDependencies фронтенду та написати тести для критичних шляхів.

8. **Встановити Definition of Done** — Жодна функція не повинна вважатися "готовою" без: робочого коду, тестів, PR review та документації.
