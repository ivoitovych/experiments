## 1. Резюме

### Загальна картина

Тестування прототипу сайту Нововолинської ЦМЛ (https://prototype-novovolynsk-cml.vercel.app/) було проведено в контрольованому середовищі з автоматизованими та аналітичними методами. **Критичне обмеження:** мережевий доступ до домену `vercel.app` заблоковано проксі-сервером тестового середовища, що унеможливило візуальний огляд та інтерактивне тестування.

### Ключові показники

| Метрика | Значення |
|---------|----------|
| Загальна кількість тест-кейсів | 151 |
| Виконано (з результатом) | 52 |
| Заблоковано (мережеве обмеження) | 99 |
| URL-аналіз | PASS |
| Мережева доступність | BLOCKED |
| Правовий аналіз | 9 критичних вимог ідентифіковано |
| Платформенний аналіз | Vercel/Next.js — стандартна конфігурація |

### Критичний блокер

> **BLOCKER-001:** Усі мережеві тести заблоковані проксі-сервером середовища.
> - Причина: домен `*.vercel.app` не входить до allowed-листа корпоративного проксі
> - HTTP-відповідь проксі: `403 Forbidden` (`x-deny-reason: host_not_allowed`)
> - Вплив: неможливість виконання 65% запланованих тестів
> - Рекомендація: повторити тестування з середовища без мережевих обмежень

### 4.2. Безпека (TC-SEC)

#### Очікувана конфігурація безпеки (Vercel defaults)

> **Примітка:** Наступний аналіз базується на стандартній конфігурації Vercel. Фактичний стан потребує перевірки з незаблокованого середовища.

| ID | Тест-кейс | Очікуваний стан | Ризик | Рекомендація |
|----|-----------|----------------|-------|--------------|
| TC-SEC-001 | Content-Security-Policy | NOT SET (Vercel default) | ВИСОКИЙ | Додати через `next.config.js` headers |
| TC-SEC-002 | X-Content-Type-Options | NOT SET (Vercel default) | СЕРЕДНІЙ | Додати `nosniff` |
| TC-SEC-003 | X-Frame-Options | NOT SET (Vercel default) | СЕРЕДНІЙ | Додати `DENY` або `SAMEORIGIN` |
| TC-SEC-004 | HSTS | NOT SET (Vercel default) | ВИСОКИЙ | Додати `max-age=63072000` |
| TC-SEC-005 | X-XSS-Protection | NOT SET | НИЗЬКИЙ | Додати `1; mode=block` (legacy) |
| TC-SEC-006 | Referrer-Policy | NOT SET | СЕРЕДНІЙ | Додати `strict-origin-when-cross-origin` |
| TC-SEC-007 | Permissions-Policy | NOT SET | СЕРЕДНІЙ | Обмежити camera, microphone, geolocation |
| TC-SEC-008 | Cookie attributes | Невідомо | ВИСОКИЙ | Перевірити Secure, HttpOnly, SameSite |
| TC-SEC-009 | Server header | Vercel (стандарт) | НИЗЬКИЙ | Прийнятно для Vercel |
| TC-SEC-010 | X-Powered-By | Можливо Next.js | НИЗЬКИЙ | Вимкнути через `poweredByHeader: false` |
| TC-SEC-011 | XSS в формах | Невідомо | ВИСОКИЙ | Потребує ручної перевірки |
| TC-SEC-012 | URL parameter injection | Невідомо | ВИСОКИЙ | Потребує ручної перевірки |
| TC-SEC-013 | Clickjacking | Залежить від X-Frame-Options | СЕРЕДНІЙ | Перевірити з iframe |
| TC-SEC-014 | Directory listing | Невідомо | СЕРЕДНІЙ | Перевірити /_next/, /public/ |
| TC-SEC-015 | Source maps | Невідомо | НИЗЬКИЙ | Вимкнути в production |

#### Рекомендована конфігурація безпеки для `next.config.js`:

```javascript
// next.config.js — рекомендовані security headers
const securityHeaders = [
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'X-XSS-Protection', value: '1; mode=block' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  { key: 'Strict-Transport-Security', value: 'max-age=63072000; includeSubDomains; preload' },
  { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },
  { key: 'Content-Security-Policy', value: "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline';" },
];

module.exports = {
  poweredByHeader: false,
  async headers() {
    return [{ source: '/:path*', headers: securityHeaders }];
  },
};
```
